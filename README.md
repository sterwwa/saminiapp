# Бот расписания СА-2/25

Telegram-бот: берёт расписание с https://guspoliteh.ru/studentu/raspisanie-zanyatiy/ и каждый день в 20:00
(Europe/Kaliningrad) отправляет его на следующий день в беседу. Следит за изменениями.

## Как бот получает данные
Обычный HTTP-запрос, без браузера: `POST` на страницу расписания с полями
`id=<id группы>`, `date=ГГГГ-ММ-ДД`, `modal2=true` (так делает скрипт `cal.js` сайта).
Id группы бот каждый раз берёт со страницы по названию «СА-2/25». Ответ — HTML-фрагмент, разбирается в `lesson_parser.py`.
В дни без занятий сайт отвечает «нет данных» — бот пишет «Занятий нет».

## Файлы
`bot.py` (запуск, команды, планировщик), `schedule.py` (запросы к сайту), `lesson_parser.py` (разбор HTML),
`formatting.py` (текст сообщений), `state.py` (состояние в `data/state.json`), `bells.py` + `bells.json` (время пар), `webapp_server.py` + `tgauth.py` + `webapp/index.html` (Mini App), `tests/`, `samples/`.

## Переменные окружения
`BOT_TOKEN` (обязательно, только в окружении или `.env`), `CHAT_ID`, `TIMEZONE`, `GROUP_NAME`.
Необязательные: `SEND_HOUR` (20), `CHECK_MINUTES` (30), `CHECK_DAYS_AHEAD` (3), `DATA_DIR` (data), `REMIND_MODE`, `REMIND_MINUTES`, `PIN_DAILY`, `ADMIN_IDS`, `BELLS_FILE`. См. `.env.example`.

## Команды
`/today`, `/tomorrow`, `/week`, `/schedule` (ближайший учебный день), `/next` (ближайшая пара и время до неё),
`/status` и `/raw ГГГГ-ММ-ДД` (для администратора), `/id` (узнать свой id). Под сообщениями — кнопки «Сегодня / Завтра / Неделя».

## Время пар — bells.json
Формат (значения подставьте из расписания звонков техникума):
```json
{"default": {"1": ["ЧЧ:ММ", "ЧЧ:ММ"], "2": ["ЧЧ:ММ", "ЧЧ:ММ"]},
 "sat": {"1": ["ЧЧ:ММ", "ЧЧ:ММ"]}}
```
`default` — для всех дней, `mon`…`sun` — необязательные переопределения для отдельных пар. Пока файл пуст,
время в сообщениях не показывается, напоминания не отправляются, `/next` сообщает, что время не заполнено.

## Напоминания, закрепление, администратор
- Напоминание о паре за `REMIND_MINUTES` (30) минут: `REMIND_MODE=first` (только первая пара, по умолчанию), `all` (каждая), `off`.
- Вечернее сообщение закрепляется, прошлое откреплается (`PIN_DAILY=1`). Боту нужны права администратора беседы с правом «Закреплять сообщения».
- `ADMIN_IDS` — id через запятую (узнать: написать боту `/id`). Если не задано, `/status` и `/raw` закрыты для всех (безопасное поведение).

## Запуск на Lunafy (панель вида Pterodactyl)
1. Вкладка **Files**: загрузите все файлы проекта в корень сервера (кроме `.env` с токеном, его создайте на месте).
2. Создайте файл `.env` по образцу `.env.example` и впишите `BOT_TOKEN` (или задайте переменные на вкладке Startup, если она есть).
3. Вкладка **Startup**: команда запуска должна выполнять `python3 bot.py`. Зависимости ставятся командой
   `pip install -r requirements.txt` (в некоторых шаблонах это происходит автоматически перед запуском — смотрите консоль).
4. Нажмите **Start** и убедитесь, что в консоли есть строка «Бот запущен».
5. Добавьте бота в беседу и дайте право писать сообщения. `CHAT_ID` — id беседы (у супергрупп начинается с `-100`).

Процесс не завершается: бот работает через long polling, планировщик живёт в том же процессе.
После перезапуска сервера состояние читается из `data/state.json`; если время 20:00 уже прошло, а расписание на завтра
не отправлялось, бот отправит его сам.

## Mini App (веб-приложение внутри Telegram)
Бот поднимает веб-сервер (aiohttp) в том же процессе. Интерфейс `webapp/index.html` содержит нижнюю навигацию: расписание, ближайшие пары, профиль и настройки. Есть дневной/недельный режим, таймлайн, статус текущей/следующей пары, свайпы, адаптация под тему Telegram, skeleton-загрузка и повтор запросов. API: `/api/week`, `/api/me`, `/api/preferences`.

Каждый API-запрос проверяет подпись Telegram `initData` через HMAC-SHA-256 и срок действия `WEBAPP_AUTH_MAX_AGE` (по умолчанию 3600 секунд). Повторяющиеся параметры initData отклоняются; добавлен простой лимит запросов на пользователя. Профиль берётся из Telegram initData. Настройки Mini App хранятся отдельно в `data/miniapp_preferences.json`.

**Важно об уведомлениях:** переключатели сохраняют пользовательские предпочтения. Они сами по себе не создают фоновые push-уведомления. Для реальной персональной рассылки, когда Mini App закрыт, потребуется отдельная логика отправки сообщений ботом и хранение подписок/разрешений. Существующие общие напоминания бота продолжают работать по `REMIND_MODE`.


**Что нужно настроить**
1. Публичный HTTPS-адрес, который ведёт на порт бота (`WEBAPP_PORT`, на панели — выданный серверу порт). Варианты:
   домен + обратный прокси (nginx/Caddy) с сертификатом, либо Cloudflare Tunnel на этот порт. Впишите адрес в `WEBAPP_URL`.
2. В @BotFather: `/newapp` → выбрать бота → указать название, описание, картинку 640×360 и **URL = WEBAPP_URL**, short name, например `schedule`.
   Полученную ссылку `https://t.me/ИМЯ_БОТА/schedule` впишите в `MINIAPP_LINK` — по ней открывается приложение из беседы.
3. По желанию в BotFather: `/mybots` → бот → Bot Settings → Menu Button, но бот и сам ставит кнопку «Расписание» (в личных чатах).
4. Перезапустить бота. Проверка: `https://ваш-адрес/healthz` отвечает `ok`; команда `/app` присылает кнопку.

**Где открывается:** в личке с ботом (кнопка меню и `/app`), в беседе — кнопка «Открыть приложение» под сообщениями бота
и `/app` (в беседах Telegram разрешает только ссылки t.me, поэтому нужен `MINIAPP_LINK`).
Ссылки с параметром: `.../schedule?startapp=tomorrow` и `?startapp=week`.

`WEBAPP_MEMBERS_ONLY=1` — пускать только участников беседы `CHAT_ID` (боту нужно видеть участников).
`WEBAPP_AUTH_MAX_AGE=3600` — допустимый возраст `initData` в секундах. Если пользователь держит приложение открытым дольше, ему может потребоваться переоткрыть Mini App из Telegram.
`WEBAPP_DEV=1` отключает проверку подписи только для запросов с localhost/loopback; на боевом сервере обязательно держите `0`.

**Проверка звонков:** `bells.json` в архиве содержит примерные интервалы и переопределение понедельника для первой пары. Это не подтверждает соответствие официальному расписанию звонков техникума. Проверьте часы у администрации/на стенде и обновите файл. Код проверяет формат, порядок начала/окончания и пересечения интервалов; предупреждения видны в логах и `/status`.

Тесты: `python tests/test_parser.py`, `python tests/test_bells.py`, `python tests/test_tgauth.py`, `python tests/test_webapp_api.py` (либо `python -m pytest`, если установлен pytest).
